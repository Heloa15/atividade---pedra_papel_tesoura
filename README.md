## Sobre o jogo

- > O projeto é uma versão divertida do clássico Pedra, Papel e Tesoura, adicionando também as opções Lagarto e Spock, inspiradas na famosa variação popularizada pela série The Big Bang Theory.

### Regras do jogo
```
✂️ Tesoura corta 📄 Papel
📄 Papel cobre 🪨 Pedra
🪨 Pedra quebra 🦎 Lagarto
🦎 Lagarto envenena 🖖 Spock
🖖 Spock esmaga ✂️ Tesoura
✂️ Tesoura decapita 🦎 Lagarto
🦎 Lagarto come 📄 Papel
📄 Papel desmente 🖖 Spock
🖖 Spock destrói 🪨 Pedra

E como sempre:

🪨 Pedra quebra ✂️ Tesoura

```
